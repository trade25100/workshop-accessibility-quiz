# workshop-accessibility-quiz

Projet HTML/CSS freeCodeCamp : Accessibility Quiz.

## Déploiement GitLab Pages

1. Créer un projet GitLab nommé `workshop-accessibility-quiz`.
2. Ajouter à la racine `index.html`, `styles.css` et `.gitlab-ci.yml`.
3. Faire un commit sur la branche par défaut.
4. Vérifier **Build > Pipelines**, puis trouver l'URL sous **Deploy > Pages**.

Le formulaire conserve son action originale vers freeCodeCamp. GitLab Pages héberge uniquement le site statique et ne traite pas les soumissions.
